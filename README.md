Cada cpp funciona separadamente então compile e execute de forma separada
Como se deve executar cada um via linha de comando:

noRepeat: <./prog> <arquivo.txt> <m>
repeat: <./prog> <arquivo.txt> <m> <n>
union: <./prog> <arquivo.txt> <arquivo.txt> <m> <n> <p>
sequence: <./prog> <arquivo.txt>

Obs:o arquivo é referente ao conjunto e cada elemento deve ser separado por virgula dentro do arquivo, exemplo: 10,-2,-8,15,3
